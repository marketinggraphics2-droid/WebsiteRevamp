How to use this document

One design language for every DynamIQ page.

The homepage is the benchmark. Every component below is lifted from the live theme stylesheet with its responsive rules attached, rendered live in an isolated frame, and paired with copy-ready HTML and CSS. Build new pages by composing these blocks — do not invent new colours, radii, type sizes or button styles.

01Load Roboto + the basePaste the “Tokens & base” block once into your global stylesheet and link the Roboto Google Font. Every component depends on it.
02Pick componentsEach card has an HTML tab and a CSS tab. Copy both; the CSS already includes its media queries and reduced-motion rules.
03Check the “Requires” tabSome blocks reuse smaller ones (buttons, tags, form fields). The tab lists what else to paste so nothing renders unstyled.
04Test the three widthsUse the Desktop / Tablet / Mobile toggles above every preview. Desktop sections are composed to fit one viewport; mobile keeps natural height.
